# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]
- Granting Accessibility is a drag and a switch: Grant opens System Settings at the Accessibility pane and puts a card under its window holding Isthmus's icon to drag into the list, so nobody has to find the app behind "+". The system's own prompt is no longer raised.
- Granting Accessibility takes effect at once: Isthmus notices the grant within a second (tccd's change notification, and a faster poll while it waits) and installs the event tap without a restart. When macOS still refuses the tap with the grant in place, the app restarts itself once instead of asking the user to.
- Isthmus makes a Mac's keyboard and mouse behave the way Windows taught your hands, from a menu-bar app that needs macOS 13 or later. A new install starts switched off and changes nothing until it is switched on; switching it off puts everything back.
- Each Windows-style keyboard gets a HID key mapping on its own services: Ctrl acts as Command, and Win and Alt sit where Windows puts them. The mapping reaches every app, password fields included. Whether a keyboard has a PC or a Mac modifier row is detected and can be corrected, and a keyboard left in Mac style is not touched. Keyboards that send media keys on F1–F12 get standard function keys in Windows style.
- An event tap translates the Windows shortcuts one key cannot express: Home and End by line, Ctrl+arrows and Ctrl+Backspace by word, Ctrl+Home and Ctrl+End, Alt+Tab with the switcher held open while Alt is held, Alt+F4, Win+D, Win+E, Win+L, Win+Tab, Win+arrows (macOS 15 tiling), Win tapped alone for Spotlight, Ctrl+Shift+Esc, Ctrl+Alt+Delete, PrintScreen and Win+Shift+S, and fixes for browsers, VS Code, Office and Finder. Ctrl+Q, Ctrl+H, Ctrl+M and Ctrl+Tab are kept from becoming Quit, Hide, Minimize and the app switcher. The shortcuts come in eight groups that switch separately, and need Accessibility.
- The app in front decides how Ctrl behaves. Terminals keep Ctrl as Ctrl and copy and paste with Ctrl+Shift+C/V; JetBrains IDEs, Emacs and Vim keep Ctrl; virtual machines and remote desktops get every key by position with nothing translated. The user's own rules, by bundle id or prefix, win over the built-in lists.
- Each wheel mouse gets Windows wheel habits: rolling toward you scrolls down, each notch scrolls three lines (one to twelve) without acceleration, buttons 4 and 5 go back and forward, and Ctrl+wheel zooms. Trackpads and the Magic Mouse keep natural scrolling.
- Each mouse gets Windows pointer speed, Windows' 1–20 scale with "Enhance pointer precision" off, as linear tracking on macOS 14 and later; on macOS 13 acceleration is switched off instead. The gain is divided by the main display's panel pixels per point, so a mouse shared through a KVM crosses the same share of the same monitor as it does on Windows.
- The keyboard and the mouse each have their own switch, each keyboard and each mouse its own settings, and the Windows and Mac presets apply to both or either in one click. Device settings follow a device across replugs, KVM switches and restarts.
- The settings live in one file, `settings.json`, that every later version reads. A key a newer version wrote, at the top level, in the keyboard or mouse section, in a device entry or in an app rule, is kept when this version rewrites the file.
- Every HID property Isthmus writes is journalled before it is written, and put back on quit, on pause, on switching to another user and, after a crash, at the next start, never over a value someone else set meanwhile. A KVM switch or a replug gets the settings again as soon as the device reappears.
- One Isthmus changes a Mac at a time: a second copy, such as another build or `isthmus run`, runs but changes nothing.
- The `isthmus` command lists devices (`devices`), shows the status and the settings (`status`, `settings`), applies a preset (`preset windows` or `preset mac`), runs without the app (`run`), puts back what a crashed run left (`restore`) and prints what devices send (`inspect`).
